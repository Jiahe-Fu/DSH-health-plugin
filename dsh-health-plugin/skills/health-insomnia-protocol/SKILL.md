# 失眠处理协议（CBT-I）

这份协议是本插件对失眠的**临床推理路径**。工具算数字，你按这里的顺序决定说什么、不说什么。

## 第 0 步：永远先做安全筛查

**在给出任何行为方案之前**，用提问或已有的 `safety.refusals` 确认下列项目。命中任一项就**停止行为干预**，改为就医指引：

| 项目 | 该问什么 | 命中后怎么办 |
|---|---|---|
| 呼吸暂停 | 打鼾响亮？有人看到呼吸停顿或憋醒？白天极度嗜睡？ | 建议睡眠监测（多导睡眠图）。CBT-I 不能替代 |
| 不宁腿 | 静息时腿有难以忍受的想动感，活动后缓解，夜间加重？ | 查铁蛋白/周围神经，转诊 |
| 发作性睡病 | 白天突然不可抗拒地睡着？大笑时突然腿软（猝倒）？ | 睡眠专科，尽快 |
| 精神症状 / 自伤 | 情绪持续低落、兴趣丧失、早醒？有无自伤或自杀念头？ | **立即**心理危机干预（中国大陆 12356 / 120）。不做行为方案 |
| 双相情感障碍 | 有无躁狂/轻躁狂史？ | 睡眠限制**禁忌**，可诱发躁狂。转精神科 |
| 癫痫 | 有癫痫史？ | 睡眠限制可能降低发作阈值，需医生同意 |
| 妊娠 | 是否怀孕？ | 睡眠限制不适用 |
| 高风险职业 | 工作涉及驾驶、机械、高空、吊装？ | 调整期间禁止上岗，改做刺激控制与固定起床 |
| 其他睡眠障碍 | 睡行、夜惊、REM 行为障碍（做梦时打人）？ | 转诊 |

另外必须排查的**继发原因**：疼痛、夜尿、胃食管反流、甲亢、更年期潮热、哮喘、心衰、抑郁焦虑、咖啡因半衰期、轮班与倒时差、酒精戒断、部分药物（β受体阻滞剂、激素、SSRI/SNRI、支气管扩张剂、部分降压药）。

**输出要求**：命中任何一条时，先给就医指引，再解释为什么不做行为干预。不要给「也许可以试试」这类软化措辞。

## 第 1 步：判定问题类型（决定主攻方向）

看 `sleep_analyze` 的均值，按主导问题选主攻：

| 主导 | 判据 | 主攻 |
|---|---|---|
| 入睡困难型 | 入睡潜伏期 ≥30 分钟为均值主因，夜醒不显著 | 刺激控制 + 固定起床 |
| 维持困难型 | 夜间觉醒 ≥30 分钟为主因 | **先排除继发原因**，再加刺激控制 |
| 早醒型 | 比目标早 ≥30 分钟且无法再入睡 | 优先评估抑郁；睡眠限制收益有限 |
| 睡眠时相延迟 | 睡眠中点晚（如 >04:00）且固定 | 固定起床 + 逐步前移，而非压缩窗口 |
| 睡眠时相提前 | 睡眠中点过早、傍晚即困 | 光照/作息后移，转诊 |
| 卧床过多型 | 睡眠效率低但总睡眠时间正常 | 压缩卧床时间，最见效 |
| 单纯睡眠不足 | 总睡眠时间短但效率正常 | **不是失眠**，不讲 CBT-I，谈时间分配 |

## 第 2 步：CBT-I 的五个成分（按效力排序）

1. **固定起床时间**——最有效、最容易被忽略。锚点是起床，不是就寝。周末误差 ≤30 分钟。
2. **睡眠限制（压缩卧床窗口）**——按睡眠效率调整，见下节规则。这是重建睡眠压力的核心手段。
3. **刺激控制**——床只用于睡觉与性生活；约 20 分钟睡不着就离床，做安静无光的事，有困意再回床；不在床上工作、刷手机、焦虑。
4. **认知重构**——处理「今晚又完了」「必须睡够 8 小时」这类灾难化预期，以及过度关注睡眠本身（矛盾性努力：越努力睡越睡不着）。
5. **睡眠卫生教育**——**单独使用基本无效**，只能作为上述四条的配角。不要把它当成主要建议输出。

## 第 3 步：睡眠限制的具体规则

以近 14 晚为窗口，用 `sleep_analyze` 返回的 `mean.efficiency`（睡眠效率 SE = 总睡眠时间 / 卧床时间）：

| 近 14 晚平均 SE | 动作 |
|---|---|
| ≥ 90% | 卧床时间 +15~30 分钟（前移就寝时间） |
| 85%–90% | 维持不变 |
| < 85% | 卧床时间 −15~30 分钟 |

硬性约束：

- **卧床时间下限 5 小时**。到下限仍低效时不再压缩，改为固定起床 + 刺激控制 + 复查。
- **单次调整不超过 30 分钟**，每 3–7 天按新的 7 晚数据再评估一次。
- 处方形式必须落到**具体钟点**：「起床固定 06:30，卧床窗口 23:45–06:30」比「少躺一会儿」有用得多。
- 预期反应要提前说清：前 1–2 周白天更困，之后入睡更快。不提前说明，用户会在第 3 天放弃。
- 数据不足时（<7 晚）**只给固定起床时间与记录要求**，不调整窗口。

## 第 4 步：就诊准备与转诊阈值

满足任一条就明确建议就诊，并**用本插件生成睡眠日记导出**带去：

- 规律失眠 ≥3 个月、每周 ≥3 次，且影响白天功能（符合慢性失眠的时间与频率要求）
- 一线 CBT-I 与药物之间：向用户说明 **CBT-I 是慢性失眠的一线治疗**，长期效果优于安眠药且无依赖；药物由医生评估
- 出现前述任一红线或禁忌
- 行为方案执行 4 周后 SE 仍 <85% 或日间功能无改善
- 疑似其他睡眠障碍

## 记录要求（必须向用户交代）

一份能用的睡眠日记需要每晚四项：**上床时间、入睡耗时、夜间觉醒合计时长、起床时间**。有咖啡因/酒精/关屏时间更好（`sleep_log` 的 `caffeine`/`alcohol`/`screens_off`）。睡眠效率依赖这四项，缺项会让方案失准。

## 沟通原则

- **不做诊断**。说「这符合慢性失眠的时间与频率特征」，不说「你就是慢性失眠」。
- **不调整处方药剂量**。药物问题一律转医生或药师。
- **归因要克制**。相关性有样本量，明说「这是相关，不是因果」。
- **不给绝对承诺**。「通常 2–4 周见效」而不是「一定能好」。
- **不把睡眠卫生当方案**。「睡前少看手机」是配角，不是建议的全部。
- **急症优先**：任何危及生命的征象，先给急救指引（120），再谈睡眠。
- **本插件不是医疗器械**，必要时明确告知用户。
